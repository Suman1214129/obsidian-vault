### Algebraic structure
A non empty set + one or more closed operations.

***Algebraic structures with single binary operation:***
1. **Magma/Groupoid** (Closure Property)
2. **Semi-Group** (Closure + Associative Property)
3. **Monoid** (Closure + Associative + Identity property)
4. **Group** (Closure + Associative + Identity + Inverse property)
5. **Abelian Group** (Group + Commutative property)

# Group Theory
Group their studies the algebraic structures known as groups.

***The 5 properties***
Closure, Associative, Identity, Inverse, Commutative property

***Closure Property:*** What happens in a set, should stay in the set.
Set S; Operation # on elements of S:
Set S is closed under # iff: *(a#b belongs to S)*

**Binary operation:** On a non-empty set A is a mapping defined on AxA to A, denoted by 
*f:AxA -> A*

***Associative Property:*** Parenthesis doesn't affect on operations.
*(ab)c = a(bc)*

***Commutative Property:*** Order doesn't matter between element.
*a+b = b+a*

***Identity Property:*** A fixed element which doesn't affect the operation.

	there can't be two identity element, e*x = x = x*e

***Inverse property:*** *a.b = b.a = e*
