
## Multimodal AI Data Intelligence Platform

LMlens is Navchetna Technologies' multimodal AI platform for intelligent data extraction, document understanding, web intelligence, and structured data generation.

Unlike traditional OCR solutions that only extract text, LMlens understands the content, context, structure, and relationships within documents, media, websites, and databases. It transforms unstructured information into structured, actionable data that can be consumed by applications, workflows, and AI systems.

Designed for developers and enterprises, LMlens acts as a unified data intelligence engine capable of processing virtually any type of digital content.

To become the universal intelligence layer that enables businesses to extract, understand, transform, and utilize data from any source without building custom extraction pipelines.

# Extraction Modes

## Raw Mode

Raw Mode extracts information exactly as it exists within the source.

It is ideal when applications require complete, unmodified extracted content.

Example output:

* Plain text
* Tables
* Metadata
* OCR output
* Images
* Layout information

---

## Enhanced Mode

Enhanced Mode transforms extracted information into structured outputs based on user requirements.

Instead of simply reading a document, LMlens understands its meaning and returns information in the desired format.

Supported output formats include:

* JSON
* YAML
* CSV
* XLSX
* TXT
* XML
* Markdown
* Custom Developer Schemas

Example:

A developer uploads an invoice and requests:

> Return supplier details, invoice number, GST number, line items and totals in my custom JSON schema.

LMlens generates the response directly in the required structure.

# Prompt2DB

Prompt2DB enables users to interact with databases using natural language.

Developers do not need to provide:

* Database Schema
* Table Names
* Column Names
* Relationships

Users simply ask questions naturally.

Examples:

* Show all pending invoices from June.
* List students who scored above 90%.
* What was the last transaction made by Customer A?
* Which employees joined after January 2025?

LMlens automatically understands the database structure and retrieves the requested information.

Supported databases include:

* SQL Databases
* NoSQL Databases
* Relational Databases
* Document Databases
